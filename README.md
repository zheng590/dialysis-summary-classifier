# 透析小结分类工作台

本项目用于辅助整理透析小结，不用于诊断或治疗决策。所有分类结果均需人工复核。规则模式仅为演示，无法可靠识别所有语义、否定和临床情况。

## 启动

在项目目录打开 PowerShell，运行：

```powershell
python server.py
```

打开 http://127.0.0.1:8000/。默认规则模式无需密钥。CSV 可直接导入；XLSX 导入需要 `python -m pip install openpyxl`。系统仅读取 XLSX 活动工作表，第一行须为不重复的表头。

## 在线 Jev

OpenRouter 需要账号和 API 密钥，调用可能收费。网页选择“在线 Jev”后可在密码框输入密钥，留空则使用服务端的 `OPENROUTER_API_KEY`；页面输入优先。不要提交密钥到代码或分享给他人。也可在 PowerShell 中设置环境变量后启动：

```powershell
$env:OPENROUTER_API_KEY = '在本机填写你的密钥'
python server.py
```

页面密钥仅保留在当前页面内存中，只随 Jev 分类请求发送给本机服务，再用于 OpenRouter 的 HTTPS 鉴权；应用不写入存储、日志或分类导出。刷新或关闭页面会丢失输入，批量开始后固定使用当时的页面密钥并禁用输入；留空时每条请求读取服务端环境变量。浏览器自动填充、扩展、开发者工具或外部代理等不受应用控制；导入文件本身若含密钥仍会随原始列导出，请勿将密钥放入小结或导入文件。服务仅绑定本机，请勿通过不可信代理暴露。密钥仅允许去除首尾空格后的可打印 ASCII 字符，最长 4096 字符，不允许内部空格和控制字符；格式校验不验证密钥是否有效。

默认模型为 `typesafe/jev-1.14`，可用环境变量 `JEV_MODEL` 修改。在线调用会把小结内容发送给第三方服务。处理患者数据前请先脱敏，并确认机构许可、第三方数据条款及跨境传输要求。未设置密钥时不会自动退回其他模式。

## JevStyle

JevStyle 是独立的第三方服务，**并非 TypeSafe 官方服务**，也不是 OpenRouter 或本地模式。选择“JevStyle”后，分类请求使用 `mode: "jevstyle"`；输入密钥时发送 `jevstyle_api_key`，页面密钥优先，留空则不发送该字段，由服务端使用 `JEVSTYLE_API_KEY`。批量处理期间固定使用开始时输入的页面密钥；留空时每条请求读取服务端环境变量。取消确认不会发送请求。页面密钥仅保留在当前页面内存中，不写入浏览器存储、应用日志或分类导出，刷新或关闭页面会丢失。请勿将密钥写入小结或导入文件；原始数据会随 CSV 导出，浏览器扩展、开发者工具和外部代理也可能看到请求内容。

可在启动服务前设置环境变量：

```powershell
$env:JEVSTYLE_API_KEY = '在本机填写你的密钥'
python server.py
```

服务端通过 HTTPS 调用 JevStyle；该模式会将小结发送至第三方，请事先脱敏并确认机构许可、服务商隐私条款和数据传输要求。未提供页面密钥且未设置环境变量时会报错，不会自动切换到其他模式。服务端对请求内容设置 8000 UTF-8 字节的保守限制，服务还会检查 token 上限。

## 本地模型

启动提供 OpenAI 兼容 `/v1/chat/completions` 接口的本机服务，然后设置：

```powershell
$env:LOCAL_MODEL_BASE_URL = 'http://127.0.0.1:1234/v1'
$env:LOCAL_MODEL_NAME = '本地模型名称'
python server.py
```

如本机服务需要鉴权，可设置 `LOCAL_MODEL_API_KEY`。出于数据安全考虑，地址限定本机回环地址。此接口面向 OpenAI 兼容生成模型，不代表已经提供本地 Jev 模型。

## 分类与验证

支持一条小结对应多个分类；原始提示词“头晕M出汗”暂按“头晕”和“出汗”两个类别处理，请结合业务口径确认。无法识别的内容显示“未分类”，不表示患者没有不适。样例 1 仅描述下肢疼痛，没有明确痉挛证据，规则模式不推断痉挛；样例 2 的规则演示返回高血压和头痛。规则模式使用固定阈值辅助识别血压，不能替代具体临床标准和人工审核。

运行自动化测试：

```powershell
python -m unittest -v test_server
node --test test_app.js
```

前端测试需要 Node.js，使用模拟 DOM 和网络请求，不替代真实浏览器及在线服务联调。
